3 * Class LinguaForge\AI\Integrations\WooCommerce\VariationDelegate
4 *
5 * Delegates WooCommerce product variation queries to the source product.
6 *
7 * Variable products have child posts of type `product_variation` attached via
8 * post_parent. In Lingua Forge's shared-stock model, translated variable
9 * products are NOT given their own variation children — the source product's
10 * variations are shared across all language versions.
11 *
12 * WooCommerce retrieves variations by querying:
13 *   SELECT … FROM wp_posts
14 *   WHERE post_type = 'product_variation' AND post_parent = {product_id}
15 *
16 * When {product_id} is a translated product, this query returns zero results
17 * because no variations are attached to the translated post. This class hooks
18 * `pre_get_posts` to intercept `product_variation` queries whose post_parent
19 * is a translated product and substitutes the source product ID instead, so
20 * WooCommerce finds the shared variations and displays the variable product
21 * correctly in all languages.
22 *
23 * No variation posts need to be created or TRID-linked.
24 *
25 * @package LinguaForge\AI\Integrations\WooCommerce
26 * @since   2.0.0
27 */
