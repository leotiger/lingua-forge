3 * Class LinguaForge\AI\Integrations\WooCommerce\CatalogQuery
4 *
5 * Adds language-awareness to WooCommerce product queries.
6 *
7 * The language-router module's QueryFilter already scopes the main shop/archive
8 * query by adding a `_lf_lang = LF_LANG` meta constraint on all frontend archive
9 * and search queries. This class extends that coverage to two additional paths:
10 *
11 * 1. WooCommerce block product queries (ProductCollection, AbstractProductGrid
12 *    blocks such as TopRated, BestSellers, OnSale, HandpickedProducts, etc.) —
13 *    handled via the `pre_get_posts` action.  These blocks create secondary
14 *    WP_Query instances (not the main query), so they are invisible to both
15 *    QueryFilter (which guards with is_main_query()) and to WC_Query's own
16 *    `woocommerce_product_query` action (also main-query-only via pre_get_posts).
17 *    We intercept every secondary WP_Query whose post_type is 'product' and
18 *    inject the language meta constraint if it is not already present.
19 *    `woocommerce_product_query` is kept as a lightweight belt-and-suspenders
20 *    fallback for any path we may have missed.
21 *
22 * 2. Related-products raw SQL queries — WooCommerce's wc_get_related_products()
23 *    calls WC_Product_Data_Store_CPT::get_related_products_query() which builds
24 *    a raw $wpdb SQL array and never goes through WP_Query (so path 1 does not
25 *    fire for it). We hook `woocommerce_product_related_posts_query` and inject
26 *    an INNER JOIN on postmeta to restrict results to the active language.
27 *    This covers both the classic related.php template and the FSE
28 *    `woocommerce/related-products` block (which calls the same function and
29 *    then puts the returned IDs into a post__in WP_Query).
30 *
31 * @package LinguaForge\AI\Integrations\WooCommerce
32 * @since   2.0.0
33 */

228     *

230     * matches the active language are included.  The JOIN alias `pm_lf_lang` is

233     *
234     * Assumption: every product post has a `_lf_lang` meta row.  Lingua Forge
235     * writes this on every save_post (class-sync.php); any pre-existing product
236     * from before LF was installed can be fixed with a single re-save or a
237     * WP-CLI command.  An INNER JOIN is therefore safe — no products are silently
238     * excluded except those that genuinely belong to a different language.
239     *
240     * Skips:
241     *  • Admin requests — product management must show all languages.
242     *  • Requests where LF_LANG is not defined or empty (REST, CLI without lang).
243     *
244     * @param array $query      SQL fragment array: fields, join, where, limits.
245     * @param int   $product_id Source product ID (unused; present for filter signature).
246     * @return array Modified (or unchanged) SQL fragment array.
