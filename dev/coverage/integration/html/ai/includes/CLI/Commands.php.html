7/**
8 * Translate, retranslate, and manage AI cache for multilingual posts.
9 *
10 * ## SUBCOMMANDS
11 *
12 *   translate      Translate a post into one or more target languages.
13 *                  Creates missing TRID-linked target posts automatically.
14 *
15 *   retranslate    Force a fresh retranslation, wiping the prior cache first
16 *                  and marking the translation synced afterwards.
17 *
18 *   fill_translations      Find and fill every missing translation for a post
19 *                         across all router-active languages. Skips languages
20 *                         that already have a TRID-linked post.
21 *
22 *   missing_translations  Scan all posts of a given type and source language,
23 *                         and list every post that is missing one or more
24 *                         router-language translations. Use as a work-list to
25 *                         drive fill_translations in bulk.
26 *
27 *   cache_clear    Clear AI-result cache entries (whole table, by feature,
28 *                  or by post ID).
29 *
30 * Run `wp linguaforge <subcommand> --help` for full options and examples.
31 *
32 * @package Lingua Forge
33 *
34 * ARCHITECTURE NOTE:
35 *   WP-CLI registers `linguaforge` against this class and introspects the
36 *   docblocks of the public methods below to build `wp linguaforge <subcommand>
37 *   --help`. Each public method is a one-line forwarder into a dedicated
38 *   command class — the actual run-loop lives in TranslateCommand,
39 *   RetranslateCommand, FillTranslationsCommand, MissingTranslationsCommand,
40 *   and CacheClearCommand. The three translate-driver classes share their
41 *   helpers via AbstractTranslateCommand.
42 *
43 *   The docblocks stay on this facade so WP-CLI continues to render the same
44 *   help output without any registration changes.
45 */

48    /**
49     * Translate a post into one or more target languages.
50     *
51     * Runs the full Translation feature pipeline (cache check, JSON schema,
52     * provider retry/backoff, Compliance preset, JSON envelope parsing) for
53     * each target language, then either prints a dry-run summary or writes
54     * the translated content into the TRID-linked target-language post via
55     * wp_update_post.
56     *
57     * ## OPTIONS
58     *
59     * <post_id>
60     * : Source post ID to translate from.
61     *
62     * --to=<langs>
63     * : Comma-separated list of target language codes (e.g. fr,de,es).
64     *   Each must be present in Translation::get_languages().
65     *
66     * [--dry-run]
67     * : Generate the translation but don't write anywhere. Default behavior
68     *   without --dry-run is to apply the translation to the TRID-linked
69     *   target-language post (if one exists) via wp_update_post.
70     *
71     * [--force]
72     * : Skip the cache. Forces a fresh API call even when an unchanged-input
73     *   cache entry exists.
74     *
75     * [--draft]
76     * : When a new target post must be created (no TRID-linked post exists yet),
77     *   always create it as 'draft' regardless of the source post's status.
78     *   Without this flag the new post inherits the source status, so a published
79     *   source produces a published translation. Has no effect when a target post
80     *   already exists (wp_update_post never changes post_status).
81     *
82     * [--temperature=<float>]
83     * : Override the worker temperature (0.0–1.0). Clamped to that range.
84     *   When omitted, the feature default (0.2) plus any active Compliance
85     *   preset override applies.
86     *
87     * [--max-tokens=<int>]
88     * : Override the worker max_tokens. Useful when translating very long
89     *   pages that hit truncation with the default ceiling.
90     *
91     * [--model=<name>]
92     * : Override the worker model string (e.g. 'claude-sonnet-4-6').
93     *
94     * [--with-meta-description]
95     * : After writing each translated post, generate and save an AI meta
96     *   description for that post in its target language. The description is
97     *   stored under _linguaforge_meta_description, exactly as if the editor
98     *   had clicked "Generate Meta Description" in the post metabox. Skipped
99     *   on --dry-run (no target post exists to write to).
100     *
101     * [--debug]
102     * : Enable translation debug logging for this run. Forces debug-file writes
103     *   to wp-content/uploads/lingua-forge-debug/ regardless of the Settings
104     *   toggle, and prints the source prompt and raw API response for each
105     *   language directly in the terminal after the call returns. Provider errors
106     *   (timeouts, HTTP failures, truncation) are also echoed inline. Useful for
107     *   diagnosing a specific post without enabling debug site-wide.
108     *
109     * [--format=<format>]
110     * : Output format for the per-language results table.
111     *   ---
112     *   default: table
113     *   options:
114     *     - table
115     *     - json
116     *     - csv
117     *     - yaml
118     *   ---
119     *
120     * ## EXAMPLES
121     *
122     *   # Translate post 123 into French and German, applying to linked posts.
123     *   $ wp linguaforge translate 123 --to=fr,de
124     *
125     *   # Translate and force new posts to draft for editorial review first.
126     *   $ wp linguaforge translate 123 --to=fr,de --draft
127     *
128     *   # Dry-run with a stricter temperature to inspect quality.
129     *   $ wp linguaforge translate 123 --to=fr --dry-run --temperature=0.1
130     *
131     *   # Translate and immediately generate meta descriptions for all targets.
132     *   $ wp linguaforge translate 123 --to=fr,de --with-meta-description
133     *
134     * @when after_wp_load
135     */
136    public function translate( array $args, array $assoc_args ): void {
137        ( new TranslateCommand() )->execute( $args, $assoc_args );
138    }

163     *   When omitted, the active Behavior preset temperature is used:
164     *   Standard 0.4 / Technical 0.2 / Legal 0.1 / Creative 0.7.
165     *

167     * : Override the worker max_tokens ceiling. Useful for very long posts.
168     *

184     *   description for that post in its target language. Stored under
185     *   _linguaforge_meta_description. Skipped on --dry-run.

191     *   language directly in the terminal after the call returns. Provider errors
192     *   are also echoed inline.
193     *
194     * [--format=<format>]
195     * : Output format for the per-language results table.
196     *   ---
197     *   default: table
198     *   options:
199     *     - table
200     *     - json
201     *     - csv
202     *     - yaml
203     *   ---
204     *
205     * ## EXAMPLES
206     *
207     *   # Retranslate post 123 into French after editing the source.
208     *   $ wp linguaforge retranslate 123 --to=fr
209     *

377    /**
378     * Clear AI-result cache entries.
379     *
380     * With no options, truncates the entire wp_lingua_forge_ai_cache table
381     * (matching the Maintenance → AI Cache → "Clear AI Cache" button). Use
382     * the options to scope deletion to a single feature, a single post, or
383     * both.

390     *   prefixes: 'meta-description', 'excerpt', 'content_generator'.
391     *
392     * [--post-id=<id>]
393     * : Only clear entries for this post ID.
394     *
395     * [--yes]
396     * : Skip the confirmation prompt when truncating the whole table.
397     *
398     * ## EXAMPLES
399     *

401     *   $ wp linguaforge cache_clear --feature=translation
