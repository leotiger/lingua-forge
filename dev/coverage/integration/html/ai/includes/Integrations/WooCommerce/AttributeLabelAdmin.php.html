5 * Admin surface for translating WooCommerce product attribute labels.

253     * that are missing a translation for each target language, sends them as a
254     * single batch to the AI (reusing TermNameTranslator::translate_term_names),

263
264        if ( ! current_user_can( 'manage_options' ) ) {

269        if ( empty( $attributes ) ) {
