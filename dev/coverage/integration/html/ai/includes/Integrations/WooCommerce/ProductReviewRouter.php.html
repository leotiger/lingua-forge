4 *
5 * Implements the shared-review-pool model for translated WooCommerce products.
6 *
7 * Problem: WC attaches submitted reviews to the product post the customer is
8 * viewing. A review written on /es/producto-x lands on the translated post, not
9 * the source. The three rating meta keys (_wc_average_rating, _wc_review_count,
10 * _wc_rating_count) are already delegated to the source product via MetaDelegate,
11 * so the displayed star count is correct — but the review list shown on the page
12 * is fetched from the translated post, producing a mismatch: "12 reviews" with
13 * only 13 visible (or 0 if all prior reviews were written on the source).
14 *
15 * Fix — option (a), shared pool (mirrors WPML's approach):
16 *
17 *  1. Submission redirect (preprocess_comment):
18 *     Before a review comment is inserted, redirect comment_post_ID from the
19 *     translated product to the source product. All reviews land in one place;
20 *     WC's "verified purchase" check works correctly because line items carry
21 *     translated product IDs and WC resolves them through its own delegation.
22 *
23 *  2. Display delegation (comments_array):
24 *     When WP fetches comments for a translated product page, substitute the
25 *     source product's review list. All language pages display the same pool.
26 *
27 * Migration note: reviews written on translated products before this fix was
28 * deployed remain on those posts and are not shown by the display filter.
29 * A one-off SQL migration (reassign comment_post_ID to source) can be run if
30 * needed; no such migration is applied automatically here.
31 *
32 * @package LinguaForge\AI\Integrations\WooCommerce
33 * @since   2.3.0
