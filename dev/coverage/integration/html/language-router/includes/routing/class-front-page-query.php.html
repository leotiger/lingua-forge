3 * Class LinguaForge\Router\Routing\FrontPageQuery
4 *
5 * Substitutes the active-language front-page / blog-home block template at
6 * runtime.
7 *
8 * When a block theme ships a `front-page.html` template, WordPress applies it
9 * automatically whenever the site's front page is rendered — whether that front
10 * page is a static Page or the latest-posts listing. This class mirrors the
11 * pattern used in Search\Query::override_search_template(): it hooks into
12 * `get_block_templates` on the frontend and, when a language-specific variant
13 * exists, substitutes it for the base template so the correct localised layout
14 * is used.
15 *
16 * Two base slugs are handled, matching WordPress's own template hierarchy:
17 *   - `front-page` → `front-page-{lang}`, whenever `is_front_page()` is true.
18 *   - `home`       → `home-{lang}`, whenever `is_home()` is true. This covers
19 *     both "Your latest posts" as the site's front page (is_front_page() is
20 *     ALSO true in that case) and a dedicated "Posts page" alongside a static
21 *     front page (is_front_page() is false).
22 *
23 * When both is_front_page() and is_home() are true (posts-as-front, no separate
24 * posts page configured), `front-page-{lang}` takes priority over `home-{lang}`
25 * if it exists — mirroring WordPress's own front-page-before-home precedence —
26 * and `home-{lang}` is used only as a fallback for themes that ship `home.html`
27 * but no `front-page.html`.
28 *
29 * Each candidate is only attempted when the active theme actually ships the
30 * corresponding BASE template (`front-page.html` / `home.html`). Without this
31 * guard, a `front-page-{lang}` row that was scaffolded (and never customised)
32 * on a theme with no `front-page.html` at all would still win the priority
33 * race for every language that has one — even though WordPress itself would
34 * never select `front-page.html` at the source language, since it doesn't
35 * exist there. `TemplateDefinitions::get()` also excludes such a slot from
36 * being offered for scaffolding in the first place; this guard covers rows
37 * that already exist from before that exclusion was added, or that a
38 * developer created directly.
39 *
40 * The hook is a no-op when:
41 *   - LF_LANG is not defined (frontend without a language prefix, or admin/REST).
42 *   - Neither is_front_page() nor is_home() is true.
43 *   - The active theme has neither a matching base template nor its `-{lang}`
44 *     variant (DB or theme file).
45 * In all those cases the original `$templates` array is returned unchanged.
46 */
