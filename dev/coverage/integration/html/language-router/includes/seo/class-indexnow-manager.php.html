3 * Class LinguaForge\Router\Seo\IndexNowManager
4 *
5 * Implements the IndexNow protocol (https://www.indexnow.org/) to notify
6 * Bing, Yandex, and other participating engines when LF-managed URLs are
7 * published or updated — replacing the deprecated Bing/Yandex sitemap-ping
8 * endpoints that were shut down.
9 *
10 * ── How IndexNow works ────────────────────────────────────────────────────
11 * 1. The site generates a random key once and stores it in an option.
12 * 2. The key must be verifiable: LF serves a plain-text file at
13 *    /<key>.txt containing exactly the key string (+ newline).
14 * 3. Any URL update is pushed to https://api.indexnow.org/indexnow via
15 *    a JSON POST containing the host, the key, the key-file URL, and the
16 *    list of updated URLs.  All IndexNow-enabled engines pick it up from
17 *    the shared endpoint.
18 *
19 * ── Automatic submission ──────────────────────────────────────────────────
20 * On wp_after_insert_post (fires for both classic admin saves and REST
21 * block-editor saves), LF submits the updated post's URL and all its
22 * translation alternates so every language version is indexed promptly.
23 *
24 * ── Manual submission ─────────────────────────────────────────────────────
25 * The Sitemap panel exposes a "Submit all URLs via IndexNow" button that
26 * calls submit_all() to push every published, LF-managed URL in one batch.
27 *
28 * ── Options ───────────────────────────────────────────────────────────────
29 *   linguaforge_indexnow_key  string  The 32-char hex verification key.
30 *
31 * @package LinguaForge\Router\Seo
32 * @since   2.3.0
33 */

129    /**

131     *
132     * Split out from maybe_serve_key_file() so it can be exercised in a test
133     * without triggering the exit() that immediately follows it in the real
134     * request flow — PHPUnit cannot observe assertions made after a test method
135     * hits exit(), so the header-emission behaviour would otherwise be
136     * untestable (see the note on the matching branch in
137     * IndexNowManagerIntegrationTest).
138     *
139     * status_header( 200 ) is required, not cosmetic: the key-file URL never
140     * matches a real post/page/rewrite rule, so WordPress's own request parsing
141     * already calls status_header( 404 ) before template_redirect fires (unlike
142     * robots.txt, which has a dedicated is_robots() fast-path that bypasses 404
143     * determination entirely). Without this call the response body is correct
144     * but goes out under a 404 status line — browsers still render the body so
145     * a manual check looks fine, but key_file_reachable() and real IndexNow
146     * crawlers both require an actual 200 and will reject a 404 regardless of
147     * body content. Calling status_header() here still works because nothing
148     * has been echoed yet, so no output has been sent.
149     *
150     * A full-page cache or CDN sitting in front of WordPress does not know this
151     * response is dynamic; without explicit no-cache headers it can freeze a
152     * stale hit for this exact URL (most commonly a 404 captured before the key
153     * existed, or a previous key after rotate_key()). Logged-in admin requests
154     * typically bypass such caches, so a manual browser check can "load
155     * perfectly" while anonymous requests — including key_file_reachable()'s own
156     * self-check and real IndexNow crawlers — keep receiving the stale response.
157     * nocache_headers() prevents that split-brain by forcing every hit to run
158     * this handler fresh.
159     */

164        // calls with headers_sent() internally; this explicit header() call has

346        $all_ok = true;
347
348        foreach ( $chunks as $chunk ) {

351                'host'        => $host,
352                'key'         => $key,

354                'urlList'     => array_values( $chunk ),
355            ] );
356

358                self::SUBMIT_URL,
359                [
360                    'timeout'    => 15,
361                    'headers'    => [
362                        'Content-Type' => 'application/json; charset=utf-8',

375

377            if ( ! in_array( $code, [ 200, 202 ], true ) ) {
